# 🇸🇦 منصة «وظيفتك اليوم» | بوابة أخبار الوظائف والنتائج والنشر الآلي

منصة إخبارية سعودية متكاملة واحترافية لمتابعة أحدث الوظائف الحكومية، العسكرية، الشركات الكبرى، برامج التدريب المنتهي بالتوظيف، ونتائج القبول، مصممة وفق أحدث معايير الأداء والـ SEO والـ UX العصري المماثل لكبرى المنصات مثل "أي وظيفة" و"وظيفتك علينا"، ومزودة بـ **نظام النشر الآلي في قنوات التيليجرام والواتساب بنقرة واحدة**.

---

## 📢 ميزة النشر الآلي في قنوات التيليجرام والواتساب (Auto-Publish & Broadcast)

تم تزويد لوحة التحكم الإدارية بنظام نشر فوري يتيح لك:

1. **النشر التلقائي في قناة التيليجرام عبر البوت (Telegram Bot API)**:
   - ينشر الإعلان فوراً بتنسيق جذاب (رموز تعبيرية، خطوط عريضة، تفاصيل المسمى، الجهة، المؤهل، الرابط المباشر، ورابط القناة).
   - خيار لتفعيل **النشر التلقائي الفوري فور إنشاء الإعلان**.
   - زر خاص بجانب كل وظيفة في جدول الإعلانات: **«نشر بالقنوات»**.

2. **البث المباشر للواتساب (WhatsApp 1-Click Broadcast)**:
   - توليد منشور منسق بترميز الواتساب (`*عريض*`، فواصل، إيموجيات).
   - نقرة واحدة تفتح تطبيق/ويب واتساب مباشرة جاهزاً للإرسال لقناتك أو مجموعاتك أو جهات اتصالك.

3. **نسخ المنشور المنسق**:
   - إمكانية نسخ النص بضغطة زر لنشره في منصة X أو لينكدإن أو سناب شات.

### 🔑 خطوات تفعيل النشر عبر بوت التيليجرام (في 30 ثانية):
1. افتح تطبيق تيليجرام وابحث عن: `@BotFather`.
2. أرسل الأمر `/newbot` ثم اختر اسماً ومعرفاً للبوت (مثال: `MyJobsNotifierBot`).
3. انسخ الـ **API Token** الذي يعطيك إياه.
4. اذهب لقناتك على التيليجرام وأضف البوت كـ **مشرف (Administrator)** مع صلاحية نشر الرسائل (Post Messages).
5. ادخل للوحة التحكم: [http://localhost:3000/admin](http://localhost:3000/admin) > انقر على **«إعدادات قنوات النشر»** وضع التوكن ومعرف قناتك (مثال: `@my_channel_name`) واضغط **حفظ**.

## 🚀 التقنيات المستخدمة (Tech Stack)

- **الإطار البرمجي**: [Next.js](https://nextjs.org/) (App Router) مع تقنيات Server Components و SSG / ISR للسرعة الفائقة والأرشفة اللحظية.
- **لغة البرمجة**: TypeScript لتوفير أعلى درجات الأمان البرمجي ودقة البيانات.
- **التصميم والتنسيق**: Tailwind CSS مع ضبط كامل للغة العربية والاتجاه (RTL) وخط Cairo الرسمي والراقي.
- **الأيقونات**: Lucide React + أيقونات مخصصة لشبكات التواصل (واتساب، تيليجرام، إكس).
- **محرك البيانات**: نظام تخزين محلي ديناميكي (File-based JSON Storage / REST API) يدعم الإضافة والتعديل والحذف الفوري مع بيانات تجريبية حقيقية وشاملة.
- **محركات البحث (SEO)**:
  - دعم كامل لبيانات Google Jobs المهيكلة (`JobPosting` Schema JSON-LD).
  - خريطة موقع ديناميكية (`sitemap.xml`) تتجدد تلقائياً عند إضافة أي إعلان وظيفي جديد.
  - ملف توجيه عناكب البحث (`robots.txt`).
  - وسوم OpenGraph و Twitter Cards مخصصة مع صور وشعارات المنشآت.
  - عناوين وروابط دائمة ملائمة لمحركات البحث (SEO Slugs).

## 💻 طريقة التشغيل والتشغيل المحلي

### 1. تشغيل خادم الإنتاج السريع:
```bash
npm run start
```
ثم توجه إلى: `http://localhost:3000`

### 2. وضع التطوير:
```bash
npm run dev
```

### 3. إعادة بناء المشروع:
```bash
npm run build
```
